## 1. PROJECT SCOPE

**Project Name:** UNOS — Weather Science Educational Game

**Description:** An interactive 2D educational game teaching weather phenomena (evaporation, condensation, pressure systems, typhoon formation) through playable levels. Built with React, Phaser 3, TypeScript.

**Deliverables:**

| # | Deliverable | Description |
|---|------------|-------------|
| 1 | World Map | Interactive level selection screen |
| 2 | Tutorial Scene | Research base briefing with 3 training exercises |
| 3 | Evaporation Level | Click sun → heat ocean → create vapor bubbles |
| 4 | Condensation Level | Click vapor → form clouds |
| 5 | Pressure Level | Drag pressure cells to create wind |
| 6 | Rotation Level | Swipe to spin wind into a vortex |
| 7 | Typhoon / Boss Level | Combined mechanics with health-bar boss fight |
| 8 | Educational Facts | Science facts unlocked on level completion |

**Platform:** Web application (responsive browser-based)
